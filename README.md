## Challenges Encountered

1. **Empty folders not appearing in Git** — After creating my Week01–Week15 folders, GitHub Desktop showed 0 changed files because Git doesn't track empty folders. I solved this by adding a placeholder file inside each folder so Git would recognize and commit them.

2. **Slow internet connection** — Downloading the installers and ISO files (especially the Windows 11 Enterprise and Ubuntu ISOs) took much longer than expected because of my slow internet connection. To work around this, I let the downloads run in the background while working on other parts of the activity so I wouldn't waste time waiting.
